# play-tools contract fixtures

Sanitized upstream responses, named `<FixtureKind>.<label>.json` and holding
`{ status, body }`. They are generated by `pnpm spike:fixtures` from M0 spike
captures. Never hand-edit them to make a test pass; update `../wire.ts` instead.

`../wire.contract.test.ts` parses every 2xx fixture with the schema for its kind.
